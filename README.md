# Scadenze PS

App per cassette di pronto soccorso. **Tutto sul NAS**; sui PC solo il collegamento Desktop.

## Percorso NAS

`\\172.17.17.11\scadenza ps`

## Setup rapido (ogni PC)

1. Python 3.12+ + `pip install -r requirements.txt` (una tantum)
2. Aprire la cartella NAS → doppio clic su `Crea collegamento Desktop.bat`
3. Avviare da Desktop con l'icona croce verde

Vedi [GUIDA_USO.md](GUIDA_USO.md) / `GUIDA_USO.pdf`.
